# W2-PM3 – Footprinting with Maltego

## Project Overview

This practical cybersecurity exercise focuses on using **Maltego**, an OSINT (Open-Source Intelligence) tool, to perform domain footprinting and information gathering.

Maltego provides a graphical interface for investigating relationships between different entities, such as domains, email addresses, websites, and other publicly available information. It uses transforms to collect and visualise connections between these entities.

In this exercise, Maltego was used to investigate the `networkwalks.com` domain and explore related email address information.

## Objectives

- Understand the purpose and functionality of Maltego.
- Install and configure Maltego for OSINT investigations.
- Perform domain-based footprinting.
- Identify publicly available email address information associated with a domain.
- Understand how graphical link analysis helps visualise relationships between entities.

## Tools and Technologies

| Tool | Purpose |
|---|---|
| Maltego Graph | Conduct OSINT investigations and visualise relationships |
| Domain Entity | Represent the target domain during the investigation |
| Maltego Transforms | Retrieve related information from available data sources |

## Practical Methodology

### Step 01 – Installing and Configuring Maltego

Maltego was downloaded and installed on the Windows system. The application was launched, and the initial configuration was completed using a Maltego account.

### Step 02 – Creating a Domain Investigation

A new investigation graph was created in Maltego. A Domain entity was added, and the target domain `networkwalks.com` was configured as the starting point for the investigation.

### Step 03 – Performing Domain Footprinting

Relevant Maltego transforms were executed against the domain entity to explore associated information.

The investigation focused on identifying publicly available email address references and understanding how Maltego represents relationships between discovered entities.

### Step 04 – Reviewing Harvested Email Information

The resulting graph was examined to review the email-related information returned by the available transforms.

This demonstrated how Maltego can help security analysts organise and visualise information gathered during an OSINT investigation.

OSINT investigations should be conducted only within authorised and appropriate boundaries. Publicly available information must be handled responsibly, particularly when it involves personal or organisational email addresses.

Sensitive personal information should not be unnecessarily disclosed or misused.
